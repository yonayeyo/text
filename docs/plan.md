# Fin.do 개편 계획

> 브랜치 `findo` · 기존 프로토타입(월간 영수증)은 `claude/confident-albattani-yjxzfo` 브랜치에 백업

## 1. 개편 요약

- 탭 수는 **5개 유지**. 네 번째 탭 **도전(goal)** 자리에 **알기(learn)** 를 새로 넣습니다.
- 기존에는 화면 속 카드와 메뉴 시트에만 있던 '한 입 금융'을 알기 탭으로 모아 독립시킵니다.
- 도전 탭의 챌린지·리그·배지는 **저축 › 목표**로, 소통(절약 팁·정책 정보)은 **알기 › 팁과 소식**으로 옮깁니다.
- 홈은 단일 화면을 유지하되 구성을 바꿉니다. 실천 관련 3개 블록을 **오늘의 실천 항목(궤도)** 하나로 합칩니다.

## 2. 정보구조 (개선안)

```
Fin.do (탭 5)
├─ 홈 home ─ 단일 화면 · 구성 변경
│   ├─ 오늘 쓸 수 있는 금액
│   ├─ 정산 알림
│   ├─ 오늘의 실천 항목 (궤도)   = 첫 주 할 일 + 유형별 행동 추천 + 챌린지 통합
│   ├─ '?' 알아볼 것 조각        → 알기 › 한 입 금융
│   └─ 지금 집중할 영역
├─ 지출 spend
│   ├─ 가계부: 날짜별 결제 내역
│   ├─ 분석: 늘고 줄었나 · 작은 돈 · 돈의 흐름 · 영수증 · 한 입 금융 카드(→ 모아보기로 이동)
│   └─ 예산: 유형별 첫 카드 · 카테고리별 예산 · 줄이기 계획 · 월말 예상 지출(← 홈)
├─ 저축 plan
│   ├─ 통장: 계좌와 용도 · 비상금 · 외주비 나누기 · 저축 꺼내기 · 투자
│   ├─ 목표: 독립 자금 단계 · 계획 대비 실제
│   │        + 독립 자금 진행률(← 홈) + 챌린지 참여·인증(← 도전) + 리그 순위·배지·포인트(← 도전)
│   └─ 자동 규칙: 필수 항목 4개 · 가끔 들어오는 돈
├─ 알기 learn ─ 신규 탭
│   ├─ 한 입 금융: 영역별 개념 원반 목록 · 알아본 개념 수(12 / 56)
│   │             · 진단에서 '잘 모르겠어요' 표시한 개념 강조
│   │             · 개념 상세 (마지막 버튼 → 관련 실행 화면)
│   │             · 기존 개념 카드 3개(← 메뉴 › 한 입 금융)
│   ├─ 팁과 소식: 절약 팁·정책 정보(← 도전 › 소통)
│   └─ 상단 입력창: AI에게 물어보기(← 떠 있는 버튼, 버튼도 유지)
└─ 혜택 benefit ─ 단일 화면 (변경 없음)
    └─ 나에게 해당되는 혜택 · 신청 일정 · 흩어진 포인트 · 요약 미리보기(집중 영역이 아닐 때)

공통 (모든 탭): 알림 · 메뉴(내 진단 결과 / 연동 계좌·카드 / 알림 설정·기본 설정·재진단 / 테스트 진행자용 탭 기록)
               · AI에게 물어보기(떠 있는 버튼) · 온보딩 진단
               ※ 메뉴 › 한 입 금융 모아보기는 알기 탭으로 이동해 메뉴에서 삭제
```

## 5. 정할 것

1. **실천 카드 이미지**: 시안의 `선저축 설정`(금속 질감), `지출 확인`(숲 사진) 카드에 실제 이미지를 쓸지, 모노톤 텍스처로 통일할지. 지금 프로토타입은 회색 텍스처로 대신했습니다.
2. **frost 카드의 푸른 기운**: 시안대로 유지할지, 완전한 무채색으로 바꿀지 (`--frost-*` 토큰 3개만 바꾸면 됨).
3. **탭 아이콘 매칭**: 시안 아이콘 순서(집 · 교차 화살표 · 파이 · 레이어 · 반짝임)를 홈 · 지출 · 저축 · 알기 · 혜택에 순서대로 대응했습니다. 의도와 다르면 알려주세요.
4. **알기 상단 입력창 위치**: 시안 5에는 입력창이 없어서, 목록 위 상단에 고정 높이 48로 넣었습니다.
5. **개념 원반 썸네일**: 영역별 일러스트·색 없이 회색 원반으로 둘지.
