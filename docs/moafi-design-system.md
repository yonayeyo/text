# moafi 디자인 시스템 v1.0

> 적용 파일: [`moafi.html`](../moafi.html). CSS 맨 아래 `moafi Design System v1.0` 블록에 토큰과 컴포넌트 규칙이 모여 있습니다.
> 수치는 1x(pt = px) 기준이고, 화면은 393 × 852(iPhone 15/16)입니다.

## 참고한 체계와 가져온 것

| 출처 | 가져온 것 | moafi에 맞게 바꾼 점 |
| --- | --- | --- |
| Google **Material 3** | 색을 역할(Primary · Secondary · Tertiary · Container)로 나누는 방식, 버튼 위계(Filled · Tonal · Outlined · Text), 알약형 버튼 | Tertiary를 '경고·초과' 전용으로 좁힘 |
| Apple **HIG** | 타입 단계(Title · Body · Caption), 44pt 이상 터치 영역, 그룹형 목록(회색 바탕 + 흰 카드) | 한글 본문에 맞게 행간 1.45 |
| 국내 금융 앱(토스 · 카카오뱅크 · 네이버페이) | 회색 바탕에 그림자 없는 흰 카드, 숫자 굵게, 무채색 위주에 포인트 색 하나 | 포인트 색을 블루 하나로 두고 바이올렛·핑크는 보조로 제한 |

## 1. 원칙

1. **색은 역할로만 씁니다.** 장식 목적의 색은 쓰지 않습니다.
2. **화면의 90%는 무채색입니다.** 한 화면에 Primary로 채운 강조 카드는 하나만 둡니다.
3. **그라데이션과 글로우는 쓰지 않습니다.** 예외는 브랜드 일러스트(§6)뿐입니다.
4. **4pt 그리드를 따릅니다.** 간격·크기·반경은 4의 배수로 하고, 터치 영역은 44 이상으로 둡니다.

## 2. 컬러

### 2.1 브랜드 역할

| 역할 | 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- | --- |
| Primary | `--primary` | `#3269FF` | 주요 버튼, 선택·진행 상태, 핵심 수치, 강조 카드 1개 |
| Primary Container | `--primary-container` / `--on-primary-container` | `#EBF0FF` / `#1D45C2` | 제안 카드, 선택한 옵션, 증가 배지 |
| Secondary | `--secondary` | `#7A59FF` | 두 번째 데이터 계열(목표 계좌, 비상금 흐름) |
| Secondary Container | `--secondary-container` / `--on-secondary-container` | `#F1EDFF` / `#4B2FC4` | 목표·보상 카드, 정책 태그 |
| Tertiary | `--tertiary` | `#FF46A9` | 경고 전용: 예산 초과, 마감 임박, 읽지 않은 알림, 지출 증가 |
| Tertiary Container | `--tertiary-container` / `--on-tertiary-container` | `#FFEBF5` / `#C0186F` | 정산처럼 처리해야 할 일 |

### 2.2 뉴트럴

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--n0` | `#FFFFFF` | 카드 |
| `--bg` | `#F4F5F7` | 화면 바탕 |
| `--n100` | `#F2F4F6` | 칸 바탕(달력, 단계 상자) |
| `--n200` | `#E5E8EB` | 구분선, 칩 테두리, 진행 막대 바탕 |
| `--n300` | `#D1D6DB` | 꺼진 스위치, 점선, 아웃라인 버튼 |
| `--n500` | `#8B95A1` | 캡션, 보조 라벨 |
| `--n600` | `#6B7684` | 보조 본문 |
| `--n900` | `#191F28` | 본문, 선택한 칩, 탭바 |

### 2.3 데이터 시각화

- 1계열은 Primary, 2계열은 Secondary, 그 밖의 계열은 뉴트럴(`#B0B8C1` · `#E5E8EB`)로 칠합니다.
- 연한 블루 `#9DB6FF` · `#DCE5FF`는 같은 계열 안에서 농도를 나눌 때만 씁니다(가계부 달력 3단계).
- 늘어난 지출과 초과는 Tertiary, 줄어든 지출은 Primary로 표시합니다.

## 3. 타이포그래피

서체는 Pretendard입니다(없으면 Noto Sans KR로 대체). 로고만 점 그리드 워드마크를 씁니다.

| 단계 | 크기 / 행간 | 굵기 | 예 |
| --- | --- | --- | --- |
| Display | 40 | 700 | 홈 '오늘 쓸 수 있는 금액' |
| Title 1 | 22 / 30 | 700 | 탭 제목(지출 · 저축 · 알기 · 혜택) |
| Title 2 | 18 / 26 | 600 | 섹션 제목, 카드 제목 |
| Body 1 | 16 / 24 | 500 | 강조 본문 |
| Body 2 | 14 / 20 | 400 | 본문, 목록 |
| Caption | 12 / 16 | 400 | 설명, 라벨 |
| Micro | 10 / 14 | 400 | 축 눈금, 범례 |

금액 숫자는 700 굵기에 `tabular-nums`, 자간 −2%로 씁니다.

## 5. 컴포넌트

| 컴포넌트 | 규칙 |
| --- | --- |
| 카드 | 흰색, 반경 20, 그림자·테두리 없음. 제안은 Primary Container, 목표·보상은 Secondary Container, 현재 상황 강조는 Primary 채움(화면당 1개) |
| 버튼 | Filled(Primary 바탕 + 흰 글자) · Tonal(Container) · Outlined(`--n300` 1px) · Text. 높이 48, 작은 버튼 36 |
| 칩 · 세부 탭 | 선택하면 `--n900`로 채웁니다. 세부 탭 밑줄도 `--n900`. 파란색은 '행동'에만 남겨 둡니다 |
| 스위치 | 켜짐 Primary, 꺼짐 `--n300` |
| 진행 막대 | 바탕 `--n200`, 채움 Primary 단색 |
| 오늘의 실천 항목 | 할 일 = Primary 채움, 완료 = 흰 카드 + 체크, 새 항목 = 점선 |
| 탭바 | `--n900` 알약, 활성 탭만 흰 알약 + 라벨 |

## 6. 브랜드 일러스트(광택 블러 에셋)

- 별 · 물방울 · 구슬 3가지 모양을 블루 · 바이올렛 · 핑크 3색으로 만들어 9종입니다(`--gem-{star|drop|orb}-{b|v|p}`).
- **온보딩 첫 화면과 빈 상태에서만** 쓰고, **화면당 1개**만 둡니다.
- 카드 장식, 아이콘, 데이터 표시에는 쓰지 않습니다.
