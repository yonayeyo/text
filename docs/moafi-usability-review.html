moafi 사용성 테스트 정리

회고 인터뷰 12명(U1~U12)의 답변을 질문별로 읽고, 화면과 기능 단위로 다시 묶었어요. 항목마다 근거가 된 참가자 번호와 실제 발언을 붙였고, 참가자 번호에 마우스를 올리면 출생 연도 · 직업 · 진단 유형이 보여요. 분홍 기호(A~J)는 정보구조도의 중복 지점이에요.

먼저 고칠 5가지

여러 참가자가 같은 문제를 말했고, 앱 전체의 복잡도에 영향을 주는 것부터 골랐어요.

남길 것

여러 참가자가 다른 금융 앱(토스 · 뱅크샐러드)과 비교하며 좋았다고 말한 기능이에요. 정리할 때도 지켜야 할 moafi의 핵심이에요.

고칠 것

P0구조 · 복잡도, 먼저 P1이해 · 문구, 같이 P2작은 개선

의견이 갈린 것

참가자마다 반응이 달라서 팀이 방향을 정해야 하는 항목이에요.

추가 요청 (다음 버전 후보)

지금 프로토타입에 없는 기능이에요. 기능을 줄이는 방향과 부딪히는 것도 있으니 필요성만 기록해 두었어요.

요청참가자메모

참가자와 해석할 때 주의할 점

번호출생 · 직업진단 유형처음 누른 것
  • 12명 중 8명이 자기관리형이고 저관여형(U11) · 인지우세형(U12)은 1명씩이에요. 지식이 낮은 사용자에 대한 판단은 U4 · U11 · U12의 의견에 크게 기대고 있어요.
  • 데모 데이터가 본인 돈이 아니라서 몰입이 덜했다는 말이 있었어요(U2 · U5). 금액 변화를 놓친 원인 중 하나일 수 있어요.
  • U12는 질문 일부에 답이 없어서, 집계는 답한 사람 기준이에요.
